# Pokerkvällen (cashgame)
Lokalt: `npm install && npm start`, öppna http://localhost:3000
Moln (Render): skapa Web Service från ett GitHub-repo med dessa filer. Build: `npm install`, Start: `npm start`.
Valfritt: sätt DATA_FILE till en fil på en Persistent Disk så bord och marker överlever omstarter.
